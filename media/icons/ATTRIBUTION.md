# Social marks

GitHub: Primer Octicons mark-github-16, from https://raw.githubusercontent.com/primer/octicons/main/icons/mark-github-16.svg (MIT; see LICENSE-GitHub.txt).

X: Simple Icons X mark, from https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/x.svg (CC0; source license: https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).

The marks remain monochrome and are paired with visible link labels. They identify external destinations.

Jupiter: `JupiterLogo/logo-grayscale.svg` copied byte-for-byte from the [official Jupiter brand kit](https://github.com/jup-ag/docs/blob/main/static/files/brand-kit/jupiter-brand-kit.zip), linked by [Jupiter’s brand-kit documentation](https://developers.jup.ag/resources/brand-kit). Original grayscale geometry and file are preserved; CSS renders the icon white for the dark page. Jupiter’s mark identifies the external buy destination; no endorsement is implied.

Bags.fm: `bags.png` is a byte-identical copy of the official [site icon](https://bags.fm/icon.png?0932b26a17d58d2a), discovered in the [Bags.fm page](https://bags.fm/app-links) metadata. Its white-on-black artwork is displayed with CSS screen blending to match the dark page. Bags.fm is the sole current buy destination; the earlier Jupiter source is preserved but no runtime buy link uses it.

Telegram: `telegram.svg` from [Simple Icons](https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/telegram.svg), CC0. The exact path is rendered monochrome alongside the labeled official Salvor Labs Telegram destination.

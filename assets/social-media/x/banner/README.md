# SalvorLabs X profile banner

Art-only, full-color dusk hero adapted to a 3:1 header. The complete canonical sphere/swirl/glow is retained; the logo is placed centrally and clear of the lower-left profile-photo area. No headline or extra wordmark was added.

## Files

- [`salvorlabs-x-banner-1500x500.png`](salvorlabs-x-banner-1500x500.png) — standard lossless upload.
- [`salvorlabs-x-banner-1500x500.jpg`](salvorlabs-x-banner-1500x500.jpg) — smaller upload alternative.
- [`salvorlabs-x-banner-3000x1000.png`](salvorlabs-x-banner-3000x1000.png) — 2× export.
- Matching SVG files — editable layout with embedded raster artwork, not a fully vector scene.
- [`review/layout-preview.png`](review/layout-preview.png) — approximate avatar/crop guides; do not upload this guide image.

X recommends 1500×500 for header photos and documents that display cropping may remove 60px at the top/bottom. The logo stays within the central band; the guide is a composition aid rather than a guarantee of every client layout. [Official X guidance](https://help.x.com/en/managing-your-account/common-issues-when-uploading-profile-photo), checked 2026-10-20.

`SOURCES.json` owns the exact source hashes, layout, specification link and output inventory. The canonical transparent artwork and approved dusk clean plate are read unchanged. Export with Node/Sharp: `SALVOR_SHARP_PATH=/absolute/path/to/sharp node source/export.cjs /absolute/output/folder`. No website hero, sharing card or canonical artwork is replaced by this pack.

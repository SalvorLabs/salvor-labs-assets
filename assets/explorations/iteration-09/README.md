# Iteration 09 — spherical outline versus sparse graph

The operator rejected the first outline-only candidate's irregular outer curves and requested a true spherical form. They also questioned whether removing the graph entirely would lose identity and asked about a simplified network. This two-up compares the requested geometric sphere-section outline with a sparse network, using G08's grayscale/perspective family.

- XS09-A: smooth spherical outer arcs, central cut contours and lower base line, grayscale depth; no nodes or graph.
- XS09-B: the same form with six flat circular nodes and four links. Four front nodes form an open Y; two rear nodes have one connecting link.

Built-in ImageGen produced generated-comparison.png; PROMPT.txt records the exact request. The source copy is unchanged. These raster geometry studies are not analytic/vector masters or ratified final logos. The visual correspondence of the two forms is generated, not certified by an exact common path definition.

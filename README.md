# SalvorLabs assets

The visual identity and design work for SalvorLabs, exploring the knowledge layer of AI.

- [Approved logo pack](assets/logo/README.md): 28 PNGs and 28 matching SVGs across four treatments.
- [Social media assets](assets/social-media/README.md): X banners and platform-specific exports.
- [Canonical sphere artwork](assets/hero/l09/README.md): approved4096px transparent PNG with contained glow.
- [Light brand guide](assets/BRAND_GUIDE.md): selected artwork, wordmark, monochrome palette and scaling.
- [Logo review](assets/reviews/logo-set-01/review.html): PNG/SVG comparison at standard sizes.
- [Export definitions](assets/EXPORT_SETS.json) and [local tools](assets/tools/README.md).

The same full G08 knowledge-graph mark is used at every size, including favicons. Earlier explorations remain as source history and are not production assets.

Approved hero images, sharing cards, visual source imagery and export tooling are included under `site/media/`, `site/source/` and `site/tools/`. The runtime page and copy updates are saved separately. Current visual ownership is routed by [the site spoke](site/CLAUDE.md).
